Know what is checked

What can I build?

Self-contained HTML, CSS, and JavaScript interfaces. Working payment, login, database, and email backends are outside the current scope.

Does passing mean everything works?

No. It means the selected checks passed. Appearance, accessibility, mobile layout, and other interactions still require review. The repair loop stops after three attempts if failures remain.

How does the intended behaviour matter?

Enter a whole number from 1 to 10. The example code always adds two.

Which actions use Nebius credits?

Brief improvement, test planning, generation, and AI repairs call Nemotron through Nebius Token Factory. Local inspection and hosting make no model calls.

Is a local website public?

No. Local links work on the computer running Synthetix while its local server is active. They are not public deployments.
