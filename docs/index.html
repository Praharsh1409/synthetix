Chromium collects JavaScript exceptions, console errors and failed behavior assertions. Passed, failed and unexecuted checks remain distinct. A failure keeps your source available for review.

The planning and bounded repair workflow remains part of the project. A replacement AI backend will be connected only after it is configured and verified; the experimental model is not presented as a working public service.

Know the scope.

Is an AI service connected?

No. AI planning, generation and automatic repair are temporarily unavailable while a replacement is developed. The workspace does not collect an API key. Browser inspection, manual approved checks and code review remain available.

What code can I use?

Self-contained HTML, CSS and JavaScript frontends. Real payments, authentication, databases and email services remain outside the website-generation scope.

What does a passing result mean?

Only that the selected checks passed within their observation window. Untested interactions, appearance and accessibility still need review.

How is my work stored?

Each online visitor receives a separate temporary workspace. Download your HTML before closing or refreshing. The free host may restart or sleep. Browser restrictions and resource limits are not complete operating-system isolation; do not upload sensitive code.
